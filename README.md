# EngineEntry

Windows desktop inventory and customs management application built with C# (.NET 8 WinForms) and SQLite.

## Features
- Track engine numbers, container numbers, C78 import entry numbers/dates, suppliers, and customer invoices
- Multi-user LAN database support (`WAL` mode + configurable shared database path)
- CSV import & export for engines and customers
- Warehouse label and sales receipt printing
- Password-protected record deletion
