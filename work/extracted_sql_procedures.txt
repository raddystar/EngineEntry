### spLoginUser
```sql
-- Authenticate user
-- Parameters: UserName, Password
-- Returns: LoginStatus

DECLARE @UserID INT
DECLARE @LoginStatus BIT

SELECT @UserID = ID, @LoginStatus = CASE WHEN UserName = '{0}' AND pwdcompare('{1}', password) = 1 THEN 1 ELSE 0 END FROM Users WHERE UserName = '{0}'

-- Return login status
RETURN @LoginStatus
```
